# California Housing Price Prediction

An end-to-end machine learning pipeline that predicts median house value for California districts from 1990 census data — from problem framing through EDA, feature engineering, model selection, hyperparameter tuning, and deployment as a live app.

## Problem

A downstream investment-decision system needs an estimate of a district's median housing price. Today that estimate is produced manually by domain experts, which is slow and inconsistent. This project replaces that manual estimate with a trained regression model.

## Approach

1. **Data splitting** — stratified train/test split on income category to avoid sampling bias
2. **EDA** — geographic and correlation analysis (location, income, housing density vs. price)
3. **Feature engineering** — rooms-per-house, bedroom ratio, people-per-house, geographic similarity via KMeans + RBF kernel
4. **Preprocessing pipeline** — `ColumnTransformer` handling imputation, ratio features, scaling, and categorical encoding
5. **Model selection** — Linear Regression → Decision Tree → Random Forest → SVR, compared via cross-validation
6. **Hyperparameter tuning** — `GridSearchCV` and `RandomizedSearchCV`
7. **Evaluation** — feature importance, bias/fairness check across categories, bootstrapped 95% CI on held-out test set
8. **Deployment** — final pipeline serialized with `joblib` and served through a Streamlit app

## Results

The tuned Random Forest pipeline was selected as the final model after comparison against linear regression (underfit), a single decision tree (overfit), and SVR. Generalization error was validated on a held-out test set with a bootstrapped confidence interval.

## Running It

```bash
pip install -r requirements.txt
jupyter notebook california_housing_price_prediction.ipynb   # to reproduce training
streamlit run app.py                                          # to run the app
```

The app can also be deployed for free on [Streamlit Community Cloud](https://streamlit.io/cloud) by pointing it at this repo.
